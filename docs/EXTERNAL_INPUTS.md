# External inputs

Figure regeneration uses the released result tables, two attributed ChEMBL
snapshots, and the GSE138266 continuum and GSE328265 two-axis AnnData objects from
the processed-data assets. It does not require downloading raw sequencing data or
external databases.
Full downstream recomputation requires the original reference inputs below.

| Resource | Required location or generation step |
|---|---|
| Human GEO data | Original GSE138266, GSE194078, GSE286068, and new GSE327243/GSE328264 records; raw archives are not needed when starting from cleaned checkpoints |
| DoRothEA | `data/reference/dorothea_human_ABC.csv.gz`; retrieve the human confidence A/B/C network from the documented source version |
| Enrichr drug libraries | `data/reference/enrichr/*.gmt`; input library names and API calls are specified in script `62` |
| NIBR DRUG-seq | Metadata parquet at `data/reference/nibr-drug-seq-drug_metadata.parquet`; script `63` retrieves the targeted full-DE profiles |
| Genetic perturbation libraries | `data/reference/perturbseqr/*.gmt.gz`; library identities are specified in script `64` and the source manifest |
| In vivo CRISPR source | `data/reference/de_la_rosa_2026/`; all source filenames and direct URLs are in `SOURCE_URLS` in script `79` |
| Ortholog reference | `HOM_MouseHumanSequence.rpt`, as specified in script `79`; match the recorded checksum when possible |
| PDPK1 structures | Original PDB records 3RWP and 1Z5M in `data/reference/`; preparation and docking are implemented in scripts `65` through `71` |
| NIBR directional libraries | The named NIBR up/down GMTs for script `73` |

`reproducibility/DATA_SOURCE_MANIFEST.csv` records the original source URLs, roles,
sizes, and SHA-256 values. It is a provenance ledger, not a promise that every listed
file is mirrored or that all URLs serve the final local format. In particular,
targeted NIBR CSVs are derived from remote parquet queries and must be generated by
the source-query code rather than downloaded from the parquet URL under a CSV name.

The historical ledger also includes earlier exploratory proteomics and LTA4H
resources that are not required for the final Figures 1-5. Scripts `01` through `50`
preserve these exploratory analyses. The downstream workflow starts at the released
cleaned objects and is listed in `release_tools/reproduce_public.py --list`.

Public source files may change. Compare downloaded inputs against the recorded
checksums; do not silently substitute a later version when reproducing the frozen
analysis. The released result tables remain available for direct inspection even
when a provider has updated a reference resource.
